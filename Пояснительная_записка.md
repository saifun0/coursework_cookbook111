## ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
к курсовому проекту на тему:
«Разработка веб-приложения «Кулинарная книга и подбор блюд»

## ВВЕДЕНИЕ

Актуальность темы обусловлена возрастающей потребностью пользователей в удобных инструментах для систематизации повседневных кулинарных предпочтений. Существующие платформы зачастую перегружены избыточной информацией и рекламой. Разработка легковесного клиентского веб-приложения позволяет решить проблему быстрого поиска и фильтрации рецептов, предоставляя пользователю интуитивно понятный интерфейс и независимость от качества интернет-соединения за счет локальной обработки данных.

Цель курсового проекта – спроектировать и разработать пользовательский интерфейс веб-приложения для просмотра, поиска, фильтрации и локального сохранения кулинарных рецептов.

Задачи проекта:

1. Провести анализ существующих технологий разработки клиентских веб-приложений.

2. Изучить спецификации HTML5, CSS3 и механизмы работы JavaScript.

3. Спроектировать структуру пользовательского интерфейса.

4. Разработать программную логику работы веб-приложения.

5. Реализовать сохранение избранных рецептов в локальное хранилище браузера.

## 1. ТЕОРЕТИЧЕСКАЯ И МЕТОДИЧЕСКАЯ БАЗА ПРОЕКТА

Современная веб-разработка опирается на трехуровневую архитектуру представления: HTML для структуры, CSS для стилизации и JavaScript для логики. В ходе теоретического исследования был проанализирован стандарт HTML5, внедряющий семантические теги (<header>, <main>, <nav>), что позволяет сделать веб-страницы доступными для программ экранного доступа (Accessibility) и улучшает их индексацию поисковыми системами (SEO).

Для реализации адаптивной верстки (Responsive Web Design) исследованы спецификации Flexbox и CSS Grid. Flexbox оптимален для одномерного выравнивания (например, навигационных панелей), в то время как CSS Grid Layout предоставляет мощные механизмы для создания двумерных адаптивных макетов. Комбинированное использование этих технологий исключает необходимость применения устаревших табличных версток и флоатов.

Также было изучено развитие языка JavaScript, в особенности его асинхронная природа. Использование архитектуры клиентского рендеринга (Single Page Application подходы) обеспечивает высокую производительность, так как обработка данных, поиск и фильтрация происходят в оперативной памяти устройства пользователя.

## 2. ПРОЕКТИРОВАНИЕ ВЕБ-ПРИЛОЖЕНИЯ

На этапе проектирования был определен функционал системы. Приложение должно отображать каталог рецептов, позволять выполнять текстовый поиск по названиям, фильтровать блюда по категориям (завтрак, обед, ужин) и сохранять выбранные рецепты в список избранного.

Для визуализации логики работы были построены диаграммы UML. Диаграмма вариантов использования (Use Case) отразила взаимодействие актора (пользователя) с основными функциями приложения. Был разработан макет интерфейса с применением концепции «Mobile First», что гарантирует корректное отображение на смартфонах с последующей адаптацией под десктопные мониторы. Главный экран разделен на блок фильтров, поисковую строку и динамическую область для вывода карточек с рецептами.

## 3. РЕАЛИЗАЦИЯ И ТЕСТИРОВАНИЕ ПРОГРАММНОГО ПРОДУКТА

В практической части проекта была сформирована файловая структура приложения. Основу приложения составляют файлы index.html, файл стилей style.css и скрипт app.js. Верстка интерфейса реализована с помощью семантических тегов HTML5. Сетка карточек рецептов построена с использованием CSS Grid, где свойства repeat(auto-fit, minmax(...)) позволили добиться перестроения колонок в зависимости от ширины экрана пользователя без применения избыточных медиа-запросов (@media).

Логика приложения написана на чистом JavaScript (Vanilla JS). Исходная база рецептов представлена в виде массива объектов, каждый из которых содержит название, категорию, время приготовления, список ингредиентов и инструкции. Динамический рендеринг осуществляется посредством методов манипуляции DOM-деревом (Document Object Model).

Был реализован нечеткий поиск по строке, игнорирующий регистр символов, и механизм многоуровневой фильтрации. Особое внимание уделено реализации списка «Избранное». Для персистентного хранения данных между сессиями применено Web Storage API, а именно localStorage. Данные конвертируются в формат JSON и записываются в память браузера. При повторном открытии страницы приложение автоматически считывает сохраненные ключи рецептов и восстанавливает список избранного.

Проведенное тестирование подтвердило корректную работу всех модулей. Алгоритмы поиска выполняются без видимых задержек, макет сохраняет целостность на экранах от 320 до 1920 пикселей.

## ЗАКЛЮЧЕНИЕ

В результате выполнения курсового проекта было успешно спроектировано и разработано веб-приложение «Кулинарная книга и подбор блюд». Поставленная цель достигнута, все задачи выполнены в полном объеме. Разработанный интерфейс отличается адаптивностью, высокой скоростью отклика и предсказуемым поведением. Использование клиентской обработки данных и localStorage позволило создать приложение, способное функционировать локально.

Результаты работы могут быть использованы широким кругом пользователей для организации кулинарных рецептов. В дальнейшем возможно масштабирование проекта путем добавления функционала синхронизации с облачными базами данных и расширения базы рецептов через внешние API.
