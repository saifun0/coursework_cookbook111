# Кулинарная книга и подбор блюд

Веб-приложение для поиска, фильтрации и сохранения кулинарных рецептов. Проект выполнен в рамках курсовой работы.

## 🌟 Основные возможности
- **Поиск рецептов**: Быстрый интерактивный поиск по названию или описанию блюда.
- **Фильтрация по категориям**: Сортировка рецептов по категориям: *Завтраки*, *Обеды*, *Ужины*.
- **Избранное**: Возможность добавлять понравившиеся рецепты в список «Избранное» с сохранением данных в `LocalStorage` (список не теряется при перезагрузке страницы).
- **Случайный выбор**: Кнопка «Случайный рецепт» для помощи в выборе блюда.
- **Интерактивные модальные окна**: Просмотр подробного рецепта (ингредиенты, пошаговая инструкция, время приготовления) во всплывающем окне.
- **Темная тема**: Поддержка светлой и темной тем оформления с сохранением выбора пользователя.

## 🛠 Технологический стек
- **HTML5**: Семантическая структура приложения.
- **CSS3**: Адаптивная сетка (Grid/Flexbox), кастомные CSS-переменные для легкого переключения тем, плавные переходы и анимации.
- **Vanilla JavaScript**: Работа с DOM, фильтрация данных, интеграция с локальным хранилищем (`LocalStorage`).
- **FontAwesome**: Современные иконки для элементов интерфейса.

## 📂 Структура проекта
- `index.html` — основная разметка страницы и структура интерфейса.
- `style.css` — стили оформления приложения, включая поддержку темной темы.
- `script.js` — логика приложения, база данных рецептов, обработчики событий и работа с `LocalStorage`.
- `Пояснительная записка.docx` — текстовый документ пояснительной записки к курсовой работе.
- `Пояснительная_записка.md` — Markdown-версия пояснительной записки.

## 🚀 Запуск проекта
Проект не требует сборщиков или веб-серверов. 
Для запуска достаточно открыть файл `index.html` в любом современном браузере.
